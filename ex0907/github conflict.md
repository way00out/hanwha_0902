# Github Conflict

### 원인
    1. 동일한 코드 수정: 서로 다른 브랜치에서 같은 파일, 같은 줄의 코드를 각각 다르게 고쳤을 때

    2. 병합 시점의 차이: 원격 저장소(Remote)의 최신 코드를 로컬(Local)에 반영하지 않은 채 내 코드를 먼저 푸시(Push)하거나 병합하려 할 때

### 해결 방법
    1. 충돌 파일 확인하기 : 충돌 난 파일을 열어보면 Git이 표시해둔 특수 기호(<<<<<<<, =======, >>>>>>>)를 볼 수 있음

    2. 코드를 직접 수정하기 : 에디터(VS Code 등)에서 위 특수 기호와 원하지 않는 코드를 수정하여 저장

    3. 변경 사항 반영 및 커밋하기

    * <<<<<<< HEAD: 내 로컬 브랜치의 코드
    * =======: 기준점
    * >>>>>>> 브랜치명: 병합하려는 상대방의 코드
