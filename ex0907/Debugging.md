# Debugging

### 디버그 하는 이유
    1. 오류 원인 파악: 코드가 멈추거나 잘못된 결과가 나올 때 정확히 어느 줄에서 문제가 발생하는지 파악
    2. 실시간 변수 확인: 코드가 실행되는 동안 변수 값이 어떻게 바뀌는지 직관적으로 확인
    3. 코드 흐름 이해: 코드를 한 줄씩 실행하며 복잡한 로직이 어떻게 작동하는지 쉽게 파악
    4. 시간 절약: print 함수를 여러 번 넣고 지우는 대신, 중단점을 걸어 효율적으로 문제를 해결

### 디버그 하는 방법(VS Code)
    1. 중단점 설정 : 코드 줄 번호 왼쪽 빈 공간(여백)을 마우스로 클릭하면 빨간색 점(중단점)이 생김
    2. 디버깅 시작 : F5 키를 누르거나 상단의 디버깅 실행 버튼을 눌러 코드를 시작하면 중단점에서 멈춤
